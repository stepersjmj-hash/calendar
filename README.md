# MJ 달력 메이커

사진과 옵션을 골라 **주문제작 달력(탁상·벽걸이) 이미지**를 월별로 만들어 주는 웹앱입니다.
설치 없이 브라우저에서 바로 쓰고, 결과물은 인쇄용 해상도(300dpi) PNG/JPG 로 내려받습니다.

- 접속: **https://stepersjmj-hash.github.io/calendar/**
- 로컬 실행: 저장소를 받아 `index.html` 을 더블클릭 (폰트를 Google Fonts 에서 받으므로 인터넷 연결 필요)

## 할 수 있는 것

| 항목 | 내용 |
| --- | --- |
| 사이즈 | 탁상 세로/가로, 정사각, A4, B5, A3, 벽걸이 프리셋 또는 mm 직접 입력. 재단 여백·상단 제본 여백·해상도(150/200/300dpi) |
| 기간 | 시작 연/월부터 원하는 개월 수(1~36). 표지 포함 여부, 주 시작 요일(일/월), 항상 6줄 |
| 디자인 | 클래식 화이트 · 미니멀 라인 · 모던 컬러 밴드 · 사진 풀블리드 · 좌우 분할(가로형) · 메모 박스 · 다크 · 파스텔 · 사진 없음(대형 그리드). 포인트 색, 월 표기(영문/한글+간지), 토요일 색 |
| 추가 옵션 | 공휴일(대체공휴일 포함, 빨간색) · 24절기 · 음력 날짜(1·15일/1일/매일) · 명절·세시풍속(정월대보름, 한식, 단오, 삼복, 칠석…) · 기념일(식목일, 어버이날…) · 사용자 정의 기념일(양력/음력, 빨강 지정, 매년 반복) |
| 폰트 | 제목 / 날짜 숫자 / 작은 글씨 를 각각 선택 (Google Fonts 한글 25종: 고딕·명조·제목용·손글씨) |
| 사진 | 대량 업로드로 월별 자동 배치, 페이지마다 정렬 가이드(1장 · 좌우 2분할 · 상하 2분할 · 큰 1장+작은 2장 · 4분할 · 없음) 선택. 미리보기에서 드래그로 위치, 휠/슬라이더로 확대 |
| 표지·로고 | 표지 제목/부제, 사진 전면 또는 여백형. 로고(투명 PNG 권장)는 표지와 매월 하단 가운데 |
| 내보내기 | 현재 페이지 1장 또는 전체 ZIP. 파일명 `calendar_YYYY-MM.png` / `calendar_YYYY_cover.png` |

## 사용 순서

1. **사이즈·출력** 에서 프리셋(또는 mm 직접 입력)과 해상도를 고릅니다. 미리보기의 빨간 점선이 재단선입니다.
2. **기간** 에서 시작 연/월과 개월 수를 정합니다.
3. **디자인** 에서 템플릿을 고르고, 필요하면 포인트 색·월 표기·사진 영역 비율을 조정합니다.
4. **추가 옵션** 에서 공휴일/절기/음력/명절/기념일을 켜고, 생일·기념일 같은 사용자 정의 기념일을 등록합니다.
5. **폰트** 를 고릅니다.
6. **사진** 에서 "대량 업로드"로 한 번에 넣거나, 페이지 스트립에서 월을 골라 레이아웃·사진을 하나씩 정합니다.
   미리보기의 사진을 드래그해 위치를 옮기고, 마우스 휠이나 "확대" 슬라이더로 크기를 조절합니다.
7. **표지·로고** 에서 표지 제목과 로고를 넣습니다.
8. 상단의 **전체 ZIP 내보내기** 를 누르면 모든 페이지가 한 번에 내려받아집니다.

키보드 ← → 로 페이지를 넘길 수 있습니다.

## 작업 저장

- 설정은 브라우저에 자동 저장되지만 **사진은 저장되지 않습니다.**
- 나중에 이어서 작업하거나 다른 PC 에서 열려면 상단 **프로젝트 저장** 으로 `*.mjcal.json` 파일을 내려받아 두고,
  **프로젝트 열기** 로 불러옵니다 (사진까지 포함).

## 인쇄 참고

- 인쇄소에 맡길 때는 300dpi, 재단 여백 3mm 를 권장합니다. 사진과 배경은 재단 여백까지 채워집니다.
- 스프링 제본이면 "상단 제본 여백"을 10mm 안팎으로 주면 구멍에 글자가 걸리지 않습니다.
- 공휴일은 법정 공휴일과 대체공휴일 규칙을 자동 계산합니다. 정부가 따로 지정하는 임시공휴일은 반영되지 않으니
  필요하면 사용자 정의 기념일(빨강)로 직접 추가하세요.

## 기술

순수 HTML/CSS/JavaScript, 빌드 없음. 음력 변환은 [korean-lunar-calendar](https://github.com/usingsky/korean_lunar_calendar_js)(MIT, 한국천문연구원 기준),
24절기는 태양 황경 계산, ZIP 은 JSZip 을 사용합니다.
